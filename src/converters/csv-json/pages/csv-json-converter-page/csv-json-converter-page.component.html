Sobre o formato CSV

O formato CSV (Comma-Separated Values) representa dados tabulares em texto plano, onde cada linha corresponde a uma linha da tabela e os valores são separados por vírgulas.

A primeira linha geralmente contém os cabeçalhos das colunas. Exemplo:

nome,idade,cidade
Ana,30,São Paulo
Bruno,25,Rio de Janeiro

Valores que contêm vírgulas ou aspas devem ser envolvidos por aspas duplas. Aspas dentro do valor são representadas por duas aspas duplas consecutivas ("").

Sobre o formato JSON

O formato JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados, amplamente utilizado em APIs e configurações de sistemas.

Para a conversão CSV/JSON, o JSON deve ser um array de objetos com estrutura simples (sem aninhamento). Exemplo: 

[
  { "nome": "Ana", "idade": 30, "cidade": "São Paulo" },
  { "nome": "Bruno", "idade": 25, "cidade": "Rio de Janeiro" }
]

Estruturas JSON aninhadas (objetos dentro de objetos) não são suportadas por este conversor.
