Converter JSON para CSV

Converta dados JSON para CSV de forma rápida e precisa.

Como usar esta ferramenta

  1. Cole ou digite o conteúdo JSON no campo de entrada
  2. O JSON deve ser um array de objetos simples (sem aninhamento)
  3. Clique em Converter para realizar a conversão
  4. O resultado CSV aparecerá no campo de saída

Sobre o formato JSON

O formato JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados, amplamente utilizado em APIs e configurações de sistemas.

Para a conversão JSON → CSV, o JSON deve ser um array de objetos com estrutura simples (sem aninhamento). Exemplo: 

[
  { "nome": "Ana", "idade": 30, "cidade": "São Paulo" },
  { "nome": "Bruno", "idade": 25, "cidade": "Rio de Janeiro" }
]

Estruturas JSON aninhadas (objetos dentro de objetos) não são suportadas por este conversor.
