Converter Texto para Binário

Converta texto em código binário e binário em texto de forma rápida e precisa.

Como usar esta ferramenta

Escolha o modo de conversão e insira o valor no campo de origem. O resultado será calculado automaticamente.

Sobre a Conversão de Texto para Binário

A conversão de texto para binário representa cada caractere pelo seu valor numérico na tabela ASCII (ou Unicode/UTF-8), expresso em base 2 (binário).

Cada caractere é convertido em um grupo de 8 bits (1 byte). Por exemplo:

  • A letra A tem valor ASCII 65, que em binário é 01000001
  • A letra a tem valor ASCII 97, que em binário é 01100001
  • O número 0 tem valor ASCII 48, que em binário é 00110000

Para converter binário de volta para texto, cada grupo de 8 bits é interpretado como um número decimal, que corresponde ao caractere na tabela ASCII.
