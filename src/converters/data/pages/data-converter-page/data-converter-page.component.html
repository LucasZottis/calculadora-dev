Informações sobre Unidades de Dados

Dados digitais representam a quantidade de informação armazenada ou transmitida, expressa em diferentes unidades conforme o contexto tecnológico. Diversos padrões de medição são utilizados mundialmente:

  • Unidades básicas: Bits (b) e Bytes (B)
  • Sistema Binário (base 2): Quilobyte (1 KB = 1024 B), Megabyte (1 MB = 1024 KB), Gigabyte (1 GB = 1024 MB), Terabyte (1 TB = 1024 GB)
  • Sistema Decimal (base 10): Quilobyte (1 KB = 1000 B), Megabyte (1 MB = 1000 KB), Gigabyte (1 GB = 1000 MB), Terabyte (1 TB = 1000 GB)

Todos os cálculos são realizados com alta precisão utilizando fatores de conversão internacionalmente reconhecidos. A unidade base adotada para as conversões é o Byte (B).
