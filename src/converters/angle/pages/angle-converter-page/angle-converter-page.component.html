Informações sobre Unidades de Ângulo

O ângulo é uma grandeza geométrica que representa a abertura entre duas semirretas com origem em um mesmo ponto. Existem diferentes unidades utilizadas para medir ângulos:

  • Grau (°): a unidade mais comum no cotidiano, onde uma volta completa equivale a 360°
  • Radiano (rad): a unidade padrão do Sistema Internacional, utilizada em matemática e física; uma volta completa equivale a 2π rad
  • Grado/Gon (gon): sistema centesimal onde uma volta completa equivale a 400 gon, muito utilizado em topografia e engenharia

Todas as conversões são realizadas com alta precisão, utilizando o Radiano como unidade base conforme o Sistema Internacional de Unidades.
